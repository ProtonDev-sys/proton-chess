# Reserved budget for bounded human play

## Problem

The proof-checked move selector worked at fixed depth, but bounded searches normally consumed all available nodes or reached the hard clock before selection. That set the same stop flag used for real cancellation, so timed and node-limited human modes almost always returned the root best. The Elo control existed but did little during actual play.

## Change

- Added a main-search phase budget that is separate from real stop, deadline and external-cancellation state.
- For positive-loss human modes, reserved half of a node cap for selection. For timed searches, the main phase stops at the earlier of its ordinary soft deadline or half the hard budget.
- Cleared only the internal main-budget flag before selection. Real node exhaustion, hard deadlines, caller deadlines and external stops remain sticky.
- In bounded mode, sampled one PVS-plausible candidate and spent the reserve on the authoritative fresh same-depth restricted search. An incomplete or out-of-band result falls back to the completed root best.
- Kept the existing narrow filter and up to three confirmations for unbounded fixed-depth analysis.
- Disabled reservation when the effective loss allowance is zero. Elo 3000 therefore retains the full bounded search budget.
- Replaced the two fixed external-stop slots with a propagated list so every caller cancellation source reaches a nested verifier.
- Prevented a bounded ponder that finishes before ponderhit from starting a verifier with no activated deadline.
- Accounted for the verifier's historical one-node UCI cap overshoot when assigning its remaining node budget, keeping the parent limited search inside its absolute cap.

## Focused regressions

- Elo 800, seed 27, 3,450 nodes: main search completes depth 3, confirmation uses the reserve, a real alternative is returned, and total nodes stay at or below 3,450.
- A two-node limited search returns a legal move without exceeding two nodes.
- Full strength at 6,000 nodes remains `Qa7`, depth 5, with the existing 6,001-node accounting. Elo 3000 matches it exactly.
- A caller deadline set after completed depth 3 remains sticky across the main/selection transition and suppresses randomisation.
- A pre-hit bounded ponder uses the same move and node count as the unrestricted root search, proving no confirmation ran.
- On `rnbqkbnr/pp1ppppp/8/8/2N5/3P4/PPP1PPPP/R1BQKBNR b KQkq - 0 3`, Elo 2700 seed 32 at depth 6 admits `g8f6` with 22,000 nodes. With 7,500 nodes, confirmation exhausts the reserve and falls back to `d7d5`; total nodes remain inside the parent cap.
