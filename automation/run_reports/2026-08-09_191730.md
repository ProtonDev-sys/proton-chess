# Symmetric candidate-versus-baseline runner

- Base: `origin/main` at `d2fe552`
- Result: kept

## Problem

The calibration runner is intentionally built around Proton versus limited Stockfish. Reusing its Stockfish slot for an older Proton binary left the two engines with different configuration and seed handling, attached a nominal opponent Elo to a relative comparison, and weakened reproducibility. Editing that runner would also change the hash pinned by the Stockfish-3000 certification protocol.

## Change

- Added a separate `tools/compare_engines.py`; the pinned `tools/estimate_elo.py` remains byte-for-byte unchanged.
- Added an independent candidate/baseline schema with candidate-relative score and estimated Elo delta. It has no opponent Elo, UCI Elo range or absolute-rating field.
- Stages private copies of candidate, baseline and openings. Source bytes are hashed before and after copy, staged bytes must match, and all staged inputs are rechecked after the match.
- Inspects and plays only the staged executables while recording the resolved source paths and verified staged hashes.
- Requires both builds to expose the same complete controlled Proton option set. Both receive, in the same order: Hash, one thread, disabled book, zero book randomness, maximum skill, disabled human style, maximum human skill, the default human loss ceiling, the same per-game seed, 25 ms move overhead, zero contempt, and disabled UCI strength limiting. No `UCI_Elo` is sent.
- Derives each shared engine seed with SHA-256 over a versioned domain, match seed, pair and candidate color. Seeds are recorded as decimal strings.
- Uses a schedule derived only from the match seed. Each opening is played candidate-white then candidate-black with fresh processes and pre-clock `ucinewgame`/`isready` handshakes.
- Closes the candidate if baseline process creation fails, and closes both engines through every later exit.
- Writes the initial JSON and every game checkpoint atomically. Checkpoints remain `running`; only the completed fixed sample can emit `gain`, `regression`, `inconclusive` or a significance flag.
- Records both tool hashes because the comparator imports stable clock, lifecycle, adjudication and opening primitives from `estimate_elo.py`.

## Inference

- The statistical unit is one color-swapped opening pair.
- Reports normalized pair scores, pentanomial counts and the existing two-sided 95% Hoeffding score interval.
- Adds a conditional exact engine-label sign-flip test over complete pair scores with a user-specified one-sided alpha.
- Reports `estimated_elo_delta = 400 * log10(score / (1 - score))` with endpoint clamping, never an absolute Elo.
- The configured game count and alpha are recorded before play. The report warns against optional stopping and shared-host dependence.

## Focused tests

Ten tests cover:

- exact identical option maps, limiter ordering and absence of `UCI_Elo`;
- same-hash, missing-option and asymmetric-profile rejection;
- stable domain-separated 64-bit seeds;
- exact sign-flip probabilities, relative result fields and final-only significance;
- even game scheduling over multiple distinguishable openings;
- candidate/baseline launch order, color order, exact shared seeds and process cleanup;
- source mutation after verified staging;
- candidate cleanup when baseline launch fails;
- initial running, per-game running and final complete JSON ordering;
- staged-path role mapping, labels, paths, binary/opening/tool hashes and completed-result replacement;
- invalid path, label and alpha rejection before engine inspection.

## Limits

- The comparator is deliberately Proton-specific. It rejects builds that cannot accept the complete controlled option profile.
- The exact test is a fixed-sample decision, not a sequential test or SPRT.
- Timing noise and shared-host effects remain possible; run candidate and baseline under the same stable host load.
- The ignored smoke report is not a release artifact.
- This run changes measurement tooling only. Engine strength, Elo calibration and Stockfish certification remain outstanding.
