## Problem

The Fischer match runner preserved complete game records but could not support a result claim. Its old unpaired confidence interval had been removed after two draws produced a false zero-width interval. Long matches also wrote structured output only after the final game, so an interruption discarded all machine-readable progress.

## Change

- Treat each color-swapped opening pair as one sample instead of treating its games as independent.
- Report normalized pair scores and the five raw pair-score categories: `0.0`, `0.5`, `1.0`, `1.5`, and `2.0`.
- Add a conservative two-sided 95% Hoeffding interval over complete pair scores in `[0, 1]`.
- Record the statistical unit, seeded without-replacement schedule, confidence method, source DOI, finite-population assumption, and shared-host caveat in schema version 2.
- Add a machine-readable `significant_above_50` gate based on the lower score bound.
- Keep incomplete pairs in the raw game record while excluding them from pair-level inference. Report the complete-pair score separately from the all-completed-game score.
- Write the JSON report atomically before play and after every game, before console output. Persist the final `complete` state and completion timestamp before printing the rendered report.
- Use unique same-directory temporary files so concurrent writers do not collide before atomic replacement.
- Add ten focused tests for drawn and incomplete pairs, all five pentanomial outcomes, the significance gate, point/pair validation, per-game callbacks, multi-level report states, atomic replacement, and failed-write cleanup.
