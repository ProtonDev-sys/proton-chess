## Problem

The match runner could preserve games and calculate pair-aware bounds, but the evidence inputs were still informal. It defaulted to Proton's own opening book, accepted only move sequences from the initial position, did not pin the Stockfish release asset or adjudication dependency, and had no strict checker that rebuilt a claimed result from raw games.

## Change

- Added six-field FEN opening support without removing the existing UCI move-line format.
- Added the 200-position `UHO_Lichess_4852_v1` certification suite derived from the official Stockfish books repository.
- Added a deterministic derivation tool with pinned source commit, archive hash, extracted EPD hash, SRI, seed, selection algorithm and CC0 license metadata.
- Added a Windows AMD64 protocol manifest for 400 games against Stockfish 18 limited to Elo 3000 at `60+0.6`.
- Pinned the runner hash, `chess==1.11.2`, both engine executables, official Stockfish release asset, suite hash, engine options, seed, time control, pairing, ply cap and pass condition.
- Added a launcher that rejects wrong platforms, dirty Git trees, changed runners or dependencies, wrong engine/suite hashes, invalid or duplicate openings, and inconsistent manifest fields before play.
- Added a result checker that replays all 400 raw records against the pinned schedule, checks exact Fischer record shape and stop conditions before every move, and recomputes every aggregate and the 95% score bound before applying the strict `> 0.5` gate.
- Added focused regressions for black-to-move FENs, same-index/different-FEN pairs, deterministic derivation, protocol drift, raw-record fabrication, incomplete pairs, illegal moves, non-finite values, clock/termination shape, dependency drift, move-limit precedence, post-threefold moves and post-limit moves.
