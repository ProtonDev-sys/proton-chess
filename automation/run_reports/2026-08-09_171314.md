## Problem

Proton advertised `UCI_Elo` only through 2800, and the match runner could limit only Stockfish. It could not run a named Proton target, give each game a reproducible human seed, or distinguish a requested Stockfish rating from the rating the binary actually supports. Stockfish 18 rejects 1200 because its advertised minimum is 1320.

## Change

- Centralized the Proton UCI Elo range: minimum 800, unchanged default 2800, maximum 3000.
- Preserved the old limiter profile exactly through 2800.
- Kept skill 20 above 2800 and reduced the base intentional-loss allowance monotonically from 8 cp to 0 cp. Ceiling division reserves the zero-loss profile for 3000 alone.
- Added `--proton-elo` to the paired match runner. It configures hash and book state first, then target Elo and the per-game seed, and enables limiting last.
- Derived each seed with SHA-256 over a versioned domain, protocol seed, Proton target, effective opponent Elo, pair and Proton color. The first eight digest bytes form an unsigned big-endian value; zero maps to one.
- Recorded seeds as decimal strings so values above JavaScript's exact-integer range remain reproducible.
- Inspected both engines' advertised `UCI_Elo` bounds before play. Proton targets outside 800..3000 are rejected. Stockfish requests below its minimum are floored and both requested and effective values are recorded; requests above its maximum and duplicate effective levels are rejected.
- Left the full-strength certification Proton options unchanged and proved its launcher never passes `--proton-elo`.
- Hardened the certification checker for the new optional metadata without rejecting older schema-2 reports that omit it.

## Evidence

- Native tests compare every 800..2800 profile against the previous formula, check monotonic 2801..3000 behavior and verify endpoint clamping.

- The result-checker suite has 16 passing tests. A stripped legacy schema-2 report passes; contradictory Proton target/seed and Stockfish requested/effective/range metadata fail.
- A real two-game smoke used Proton target 1200 against requested Stockfish 1200, effective Stockfish 1320, at 0.02 seconds per move. Both colors ran with distinct exact seed strings. Proton scored 2/2, but one opening pair at this time control is only a configuration check.
